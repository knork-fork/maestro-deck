## What's new in v0.1.1

- Added ability to drag&drop selected text from notepad into terminal to paste as input
- Added plugins support, and a Claude Plan plugin that automatically opens Claude CLI in planning mode
- Reworked tabs - no longer tile types, now come with their own sidebar
- Added **Sheet** calculator tile
- Added preferences window with basic tiles settings
- Added clear all tiles button to tiles sidebar
- Added clear project and clear all projects buttons to File menu
